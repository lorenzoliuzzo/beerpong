Pills show the status of one team or row: paid, arrived, live, in call.

Variants: default (`line` background), `.ok`, `.warn`, `.accent`; and `.live-pill` (red, links to the live page) / `.live-pill.past` ("Dettagli", "📣 in chiamata").

**Roast:** the LIVE pill now appears only once a match has started, a fix since the first version. `ok` on `ok-soft` is 3.7:1 (light), and white on `err` is 2.3:1 in dark.

Group standings: position, team, played / won / drawn / lost, cup difference (DB), points.

Qualifiers get an `ok` inset stripe (`tr.q`), best thirds a `gold` stripe (`tr.q3`), your team an `accent-soft` row (`tr.mine`). Wrapped in `.table-wrap` for horizontal scroll. Macro: `ui.table(rows, T, thirds, mine)`.

**Roast:** eight columns on a 375px phone, with single-letter Italian headers (G V N P DB Pt) and no legend in the table itself.
